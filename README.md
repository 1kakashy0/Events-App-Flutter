# 🎉 Event Management Frontend

This repository contains the **frontend code** for an advanced **Event Management System** that enables event organizers and participants to seamlessly manage and engage with events.  
The application is built with **Flutter** to deliver a smooth, responsive, and cross-platform user experience.  

---

## ✨ Features
**👤 Users**
- Secure registration & authentication  
- Manage personal profile  
- Browse, register, and track events  
- Purchase tickets online *(demo payment module)*  
- View purchased tickets  
- Rate & review events  

**👨‍💼 Admin / Manager**
- Secure authentication  
- Manage users (view / remove)  
- Manage events (create, approve, reject, edit, delete)  

---

1. **Clone the repository**  
   ```bash
   git clone https://github.com/your-username/event-management-frontend.git

2. **Install dependencies**
   ```bash
   flutter pub get

3. **Run the application**
   ```bash
   flutter run

## 🔧 Backend Integration
This repository contains only the frontend.
The backend (PHP & MySQL) handles event creation, user management, and ticketing.

👉 If you need access to the backend code, feel free to contact me directly, and I will provide guidance on integration.

## 🚀 Tech Stack
- Frontend (Mobile): Flutter, Dart, GetX (state management)
- Backend: PHP
- Database: MySQL
- Realtime & Notifications: Firebase
- IDE & Tools: Android Studio, VS Code

## 🗂 Architecture
Three-tier architecture:
  1. Presentation Layer (UI)
  2. Business Logic Layer
  3. Data Persistence Layer

## 📅 Development Methodology
Developed using Agile SCRUM, divided into 3 sprints:

- Sprint 1 – Authentication & Account Management
User/admin login, signup, profiles, user management

- Sprint 2 – Event Management
Event creation, editing, deletion, approvals/rejections

- Sprint 3 – Advanced Features & Ticketing
Event browsing, searching, notifications, demo payment, reviews
